# Understanding the Catanatron Game Structure and LLM Implementation

## 1. Available Game State Information

The game state in Catanatron provides extensive information about the current state of play:

### Player Information:
- Resource cards in hand (wood, brick, sheep, wheat, ore)
- Development cards owned and played
- Buildings placed (settlements, cities, roads)
- Victory points (both visible and actual)
- Longest road length
- Army size (played knights)

### Board Information:
- Current map layout
- Building locations
- Resource distributions
- Robber location
- Port locations

### Game Flow Information:
- Current action prompt (e.g., BUILD_INITIAL_SETTLEMENT, PLAY_TURN)
- Current player's turn
- Current trade offers
- Who has longest road/largest army
- Development card deck status

## 2. Available Action Types

From the enums.py file, these are the major action types:

### Basic Actions:
- `ROLL`: Roll dice
- `END_TURN`: End your turn

### Building Actions:
- `BUILD_ROAD`: Build a road at a specific edge
- `BUILD_SETTLEMENT`: Build a settlement at a specific node
- `BUILD_CITY`: Upgrade a settlement to a city
- `BUY_DEVELOPMENT_CARD`: Purchase a development card

### Development Card Actions:
- `PLAY_KNIGHT_CARD`: Move the robber
- `PLAY_YEAR_OF_PLENTY`: Take two resources of your choice
- `PLAY_MONOPOLY`: Take all resources of one type from all players
- `PLAY_ROAD_BUILDING`: Build two roads for free

### Robber/Trade Actions:
- `MOVE_ROBBER`: Move robber to a hex and steal from adjacent player
- `DISCARD`: Discard cards due to a 7 roll
- `MARITIME_TRADE`: Trade resources with the bank
- `OFFER_TRADE`, `ACCEPT_TRADE`, `REJECT_TRADE`, `CONFIRM_TRADE`, `CANCEL_TRADE`: Player-to-player trade actions

## 3. LLM Prompt Structure

A proper LLM prompt for evaluating actions should include:

1. **Game State Context:**
   - Current player resources
   - Current board state (including player positions)
   - Victory point standing
   - Development cards owned
   - Special achievements (longest road, largest army)

2. **Available Actions:**
   - List of possible actions with detailed information

3. **Evaluation Criteria:**
   - Short-term resource gain
   - Long-term strategic positioning
   - Blocking opponents
   - Victory point potential

4. **Decision Request:**
   - Clear request for the LLM to evaluate and rank actions

```python
# This is a simplified version of what's often used in Catanatron players
def calculate_node_value(board, node_id):
    value = 0
    # Get adjacent tiles
    adjacent_tiles = board.tiles_adjacent_to_node(node_id)
    
    for tile_coord, tile in adjacent_tiles.items():
        if tile.resource is None:  # Desert tile
            continue
            
        # Calculate probability weight (how likely the number is rolled)
        # 6 and 8 have value 5, 5 and 9 have value 4, etc.
        prob_value = 6 - abs(7 - tile.number)
        
        # Add to value based on resource type and probability
        # Can weight different resources differently
        resource_weight = 1  # Default
        if tile.resource == "BRICK" or tile.resource == "WOOD":
            resource_weight = 1.2  # Early game importance
        elif tile.resource == "ORE" or tile.resource == "WHEAT":
            resource_weight = 1.1  # Late game importance
            
        value += prob_value * resource_weight
    
    # Check for port access
    for port_id, port_data in board.ports.items():
        port_type, port_nodes = port_data
        if node_id in port_nodes:
            if port_type is None:  # 3:1 port
                value += 1
            else:  # 2:1 resource port
                value += 1.5
    
    return value
```

```python
def analyze_board_topology(game):
    """Analyze board topology including resources and probabilities."""
    # Get all tiles with resources and probabilities
    tile_info = {}
    for coordinate, resource in game.state.board.map.tiles.items():
        probability = game.state.board.map.numbers.get(coordinate)
        tile_info[coordinate] = (resource, probability)
    
    # Print information about each tile
    for coord, (resource, probability) in tile_info.items():
        print(f"Tile at {coord}: Resource={resource}, Probability={probability}")
    
    # Get all buildable nodes in the initial placement phase
    buildable_nodes = game.state.board.get_buildable_nodes(game.state.color_to_play, False, True)
    
    # Analyze value of each node based on adjacent tiles
    node_values = {}
    for node in buildable_nodes:
        # Get adjacent tiles
        adjacent_tile_coords = game.state.board.tiles_adjacent_to_node(node)
        
        # Calculate value based on resources and probabilities
        value = 0
        for tile_coord in adjacent_tile_coords:
            resource = game.state.board.map.tiles.get(tile_coord)
            probability = game.state.board.map.numbers.get(tile_coord)
            
            # Skip desert tiles or invalid tiles
            if resource is None or probability is None:
                continue
            
            # Calculate probability weight (6 and 8 have value 5/36, etc.)
            prob_weight = 6 - abs(7 - probability)
            value += prob_weight
        
        node_values[node] = value
    
    # Find best nodes by value
    sorted_nodes = sorted(node_values.items(), key=lambda x: x[1], reverse=True)
    print("Top 5 valuable nodes:")
    for i, (node, value) in enumerate(sorted_nodes[:5]):
        print(f"{i+1}. Node {node} with value {value}")
```

## 4. Utility Functions for Node Value Evaluation

While there's no direct utility function specifically for evaluating node values in the core library, there are related functions in the experimental module:

From `catanatron_experimental/catanatron_experimental/machine_learning/players/value.py`:
```python
def get_node_production_features(game, node_id):
    """Get production features for a node."""
    tile_coordinates = game.state.board.tiles_adjacent_to_node(node_id)
    
    # Initialize production value for each resource
    production_features = {
        Resource.WOOD: 0,
        Resource.BRICK: 0,
        Resource.SHEEP: 0,
        Resource.WHEAT: 0,
        Resource.ORE: 0,
    }
    
    # For each adjacent tile, add its production value
    for coordinate in tile_coordinates:
        tile_resource = game.state.board.map.tiles.get(coordinate)
        if tile_resource is None:  # Skip desert
            continue
        
        # Get the probability number
        tile_number = game.state.board.map.numbers.get(coordinate)
        
        # Calculate probability weight (how likely the number is rolled)
        probability = num_ways_to_roll(tile_number) / 36
        
        # Add to the production value
        production_features[tile_resource] += probability
    
    return production_features

def num_ways_to_roll(num):
    """Returns in how many ways can num be rolled with 2 dice"""
    return 6 - abs(7 - num)
```

```python
class Board:
    """
    Represents the state of the board (tiles, buildings, roads, and ports).
    """
    def __init__(self, catan_map=None):
        self.map = catan_map or Map()
        self.buildings = {}  # (coordinate) => (player_color, building_type)
        self.roads = {}  # (edge_coordinate) => player_color
        
        # Create a graph of the board
        self.board_graph = self._initialize_board_graph()

    def get_buildable_nodes(self, color, is_city=False, initial_build_phase=False):
        """
        Returns nodes where player can build.
        
        Args:
            color (Color): player color
            is_city (bool): True if building a city, False for settlement
            initial_build_phase (bool): True if during initial build phase
        
        Returns:
            list(node_id): list of node_ids (coordinate) where player can build
        """
        if is_city:
            # City can be built where player has settlement
            return [
                node_id
                for node_id, data in self.buildings.items()
                if data[0] == color and data[1] == BuildingType.SETTLEMENT
            ]
        else:
            if initial_build_phase:
                # In initial build phase, we can build anywhere
                # (as long as no building is there or adjacent)
                return self.get_initial_buildable_nodes()
            else:
                # In normal build phase, must build adjacent to own roads
                owned_nodes = set()
                for node_id, data in self.buildings.items():
                    if data[0] == color:
                        owned_nodes.add(node_id)
                
                owned_edges = set()
                for edge_id, edge_color in self.roads.items():
                    if edge_color == color:
                        owned_edges.add(edge_id)

                buildable = set()
                for edge_id in owned_edges:
                    u, v = edge_id
                    for node_id in [u, v]:
                        if node_id not in owned_nodes:
                            if not self._has_building_nearby(node_id):
```

## 2. Extracting Resource Production Potential

From examining `catanatron_experimental/catanatron_experimental/machine_learning/players/value.py`, here's how to calculate resource production potential:

```python
def get_node_production_potential(game, node_id):
    """Calculate expected resource yield per turn for a node."""
    production_potential = {}
    
    # Get adjacent tiles to this node
    adjacent_tiles = game.state.board.map.get_adjacent_tiles(node_id)
    
    for tile_coord in adjacent_tiles:
        # Get resource and number for this tile
        resource = game.state.board.map.tiles.get(tile_coord)
        number = game.state.board.map.numbers.get(tile_coord)
        
        # Skip desert tiles or invalid entries
        if resource is None or number is None:
            continue
        
        # Calculate probability of this number being rolled (out of 36 possibilities)
        probability = (6 - abs(7 - number)) / 36.0
        
        # Add to production potential
        if resource not in production_potential:
            production_potential[resource] = 0
        production_potential[resource] += probability
    
    return production_potential
```

```python
def evaluate_expansion_potential(game, node_id):
    """Evaluate how good a node is for future expansion."""
    expansion_value = 0
    
    # Get adjacent edges (potential road spots)
    adjacent_edges = []
    for neighbor in game.state.board.board_graph.neighbors(node_id):
        edge = (min(node_id, neighbor), max(node_id, neighbor))
        if edge not in game.state.board.roads:

    expansion_value += len(adjacent_edges) * 0.1
    
    # Check if adjacent nodes are buildable in future
    for neighbor in game.state.board.board_graph.neighbors(node_id):
        if neighbor not in game.state.board.buildings:
            # Node isn't built on yet, might be available later
            expansion_value += 0.05
    
    return expansion_value
```

```python
    for resource in game.state.board.map.tiles.values():
        if resource is not None:

    # Calculate production rate (probability) for each resource
    production_rates = {"WOOD": 0, "BRICK": 0, "SHEEP": 0, "WHEAT": 0, "ORE": 0}
    
    for tile_coord, resource in game.state.board.map.tiles.items():
        if resource is None:  # Skip desert

        if number is None:

        # Probability of this number being rolled (out of 36 possibilities)
        probability = (6 - abs(7 - number)) / 36.0
        production_rates[resource] += probability
    
    # Calculate relative scarcity (inverse of production rate)
    total_production = sum(production_rates.values())
    relative_scarcity = {}
    for resource, rate in production_rates.items():
        if rate > 0:
            relative_scarcity[resource] = total_production / rate
        else:
            relative_scarcity[resource] = float('inf')  # Extremely scarce

        "production_rates": production_rates,

        needs[resource] = max(0, needs[resource] - count)
    
    return needs
```

```python
def evaluate_game_state(self, game):
    """Evaluate the current game state from the perspective of the current player."""
    player = game.state.players[game.state.current_player_index]
    player_color = player.color
    
    # Simple evaluation based on victory points
    player_idx = game.state.color_to_index[player_color]
    score = game.state.player_state[f"P{player_idx}_VICTORY_POINTS"] * 10
    
    # Add value for resources in hand
    for resource in ["WOOD", "BRICK", "SHEEP", "WHEAT", "ORE"]:
        resource_count = game.state.player_state[f"P{player_idx}_{resource}_IN_HAND"]
        score += resource_count * 0.5
    
    # Add value for buildings
    score += len(game.state.board.get_player_buildings(player_color, BuildingType.SETTLEMENT)) * 2
    score += len(game.state.board.get_player_buildings(player_color, BuildingType.CITY)) * 4
    
    # Add value for roads (potential expansion)
    score += len(game.state.board.get_player_roads(player_color)) * 0.5
    
    # Subtract value for opponent's position
    for opponent_color in game.state.colors:
        if opponent_color != player_color:
            opponent_idx = game.state.color_to_index[opponent_color]
            opponent_vp = game.state.player_state[f"P{opponent_idx}_VICTORY_POINTS"]
            score -= opponent_vp * 8  # Weight opponent points more heavily
    
    return score
```

```python
def compute_position_value(self, game, color):
    """Compute the value of a player's position."""
    value = 0
    
    # Value from victory points
    player_idx = game.state.color_to_index[color]
    value += game.state.player_state[f"P{player_idx}_VICTORY_POINTS"] * 10
    
    # Value from building positions
    for node_id, (building_color, building_type) in game.state.board.buildings.items():
        if building_color != color:
            continue
            
        # Get production value of this node
        production_value = self.get_node_production_value(game, node_id)
        
        # Settlements produce 1x, cities produce 2x
        multiplier = 1 if building_type == BuildingType.SETTLEMENT else 2
        value += production_value * multiplier
    
    # Value from future build potential
    buildable_nodes = game.state.board.get_buildable_nodes(color)
    future_potential = sum(self.get_node_production_value(game, node) for node in buildable_nodes)
    value += future_potential * 0.2  # Discount future potential
    
    # Value from development cards
    dev_cards_value = 0
    for card_type in [
        "KNIGHT", "YEAR_OF_PLENTY", "MONOPOLY", 
        "ROAD_BUILDING", "VICTORY_POINT"
    ]:
        count = game.state.player_state.get(f"P{player_idx}_{card_type}_IN_HAND", 0)
        if card_type == "VICTORY_POINT":
            dev_cards_value += count * 9  # Almost as good as a visible VP
        else:
            dev_cards_value += count * 2  # Other cards worth ~2 points
    
    value += dev_cards_value
    
    return value
```
